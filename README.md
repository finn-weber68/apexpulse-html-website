## Using ApexPulse

### Run the files locally

1. Clone the repository or download its contents.
2. Open a terminal in the project directory.
3. Load the primary `.html` file in your browser.
4. Check the interface together with its linked pages and assets.

### Use a local HTTP server

Some browsers limit how local assets are loaded. In that case, launch a basic server from the project directory:

```bash
python -m http.server 8000
```

Open the local address below:

```text
http://localhost:8000
```
